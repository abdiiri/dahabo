# Dahabo Navigator

Project Name

Dahabo Global Logistics Operations Platform (DGLOP)

Project Goal

Build a modern, enterprise-grade Logistics Operations Platform for Dahabo Global Logistics Ltd.

This is not a simple CRUD logistics app.

This platform should feel like software used by companies such as DHL, UPS, FedEx, and large logistics organizations.

The project must be fully responsive, professional, scalable, and future-ready.

The application should include:

 Public Website

 Customer Portal

 Staff Portal

inside one unified application.

Do not generate backend functionality.

Use mock data everywhere.

Every page should already look production ready.
